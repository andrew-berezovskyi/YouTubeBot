# Оновлення 1.1.2 — черга, таймаути та видимий прогрес

1. Натисни «Зупинити» та закрий вікно Discovery.
2. Скопіюй вміст цього архіву прямо в C:\YouTubeBot, об’єднуючи папки та замінюючи файли.
3. Запусти START_DISCOVERY.bat. Перевстановлення залежностей не потрібне.
4. У налаштуваннях для наступного тесту залиш reddit_search: false.
   Старі Reddit-записи залишаться в історії, але не займатимуть чергу.
5. Залиш «Повторювати» та «Обробляти та завантажувати» вимкненими.
6. Натисни «Знайти й перевірити». Унизу тепер показуються поточний етап,
   час очікування та, для мережевих запитів, ліміт часу.
7. Якщо є error, виділи рядок для повного опису або прочитай журнал:

   Get-Content "C:\YouTubeBot\Logs\discovery-worker.log" -Tail 80

Нові налаштування підхоплюються автоматично без заміни твого JSON:
- search_timeout_seconds: 45 — один пошуковий запит;
- metadata_timeout_seconds: 60 — отримання даних одного ролика;
- download_timeout_seconds: залишається твоє значення (початково 600).

Це ліміти окремих операцій, не всього циклу. Кілька запитів можуть сумарно
тривати довше хвилини. OCR/AI працюють за власними лімітами й показують номер кадру.

Додано час подій, підсумок циклу, причини yt-dlp та HTTP-код RSS. Виправлено
відбір перед лімітом кандидатів: вимкнені джерела, вичерпані спроби та записи,
які очікують повтору, не забирають місця нових відео. Свіжі кандидати мають
пріоритет перед повторними помилками. У таблиці найновіші записи йдуть першими.

Щоб вручну повторити відео з error, після завершення процесу виділи його та
натисни «Повторити перевірку», потім запусти новий цикл. Для upload_uncertain
повтор не дозволяється — спершу перевір результат у Studio.

Налаштування, Tesseract-шлях, профіль Google, старі записи і check_discovery.py
не замінюються. Для worker_progress автоматично додається окрема таблиця
до існуючої discovery.db; дані кандидатів зберігаються.

22 локальні тести пройшли, зокрема вимкнені джерела, черга, редагування повідомлень,
завершення справжнього тестового підпроцесу за таймаутом і початкові тести.
Живі помилки доступу платформ на твоєму ПК ще не відтворені. Оновлення покаже
їхню причину; воно не гарантує усунення обмежень мережі або авторизації.
Windows GUI потрібно перевірити на твоєму ПК.
