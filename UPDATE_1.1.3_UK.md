# 1.1.3 — відбір Shorts у пошуку

Встановлюється поверх 1.1.2. Закрий Discovery, скопіюй вміст архіву в
C:\YouTubeBot із заміною файлів та об’єднанням папок, запусти START_DISCOVERY.bat.
Налаштування JSON, бази, Google-профіль і діагностичний файл не замінюються.

Причина: yt-dlp YoutubeSearchIE (ytsearch) застосовує Videos-only search params.
Саме слово #shorts не прибирає цей фільтр. Тепер використовується URL
https://www.youtube.com/results?search_query=... без Videos-only параметра.
Бот відбирає записи з /shorts/ URL, який yt-dlp отримує з позначки SHORTS
або відповідної адреси у видачі YouTube. Це відбір Shorts із загального пошуку,
не недокументований фільтр вкладки Shorts. Якщо видача не містить таких записів,
буде 0 результатів із поясненням; довгі звичайні відео не підставляються замість них.

За замовчуванням:
- youtube_shorts_only: true — перевіряти позначку Shorts для пошукових результатів;
- youtube_scan_limit: 40 — переглянути до 40 результатів на один пошуковий запит;
- results_per_query — як раніше, максимум відібраних записів на запит;
- min_duration і max_duration — без змін, початково 5–90 секунд.
Нові поля автоматично доповнюють старий JSON, вручну додавати їх не потрібно.

Відомі з пошуку непридатні тривалості пропускаються одразу. Якщо тривалість
невідома, запис перевіряється через metadata. Старі rejected залишаються
історією й не стають придатними. Джерела, вказані вручну в source_urls,
зберігають попередню поведінку та проходять основні перевірки.

Перший тест: reddit_search=false, обидва прапорці зверху вимкнені.
Запити можна залишити зі словом #shorts. Натисни «Знайти й перевірити».
Журнал показуватиме scanned / selected / skipped. Selected — кількість
відібраних записів, включно з уже відомими: це не завжди нові записи в базі.
Якщо selected=0, спробуй іншу тему або додай URL /shorts погодженого автора.
Точні повтори не додаються в базу вдруге.

27 локальних тестів пройшли. Нові перевіряють URL пошуку, відмінність між
хештегом і Shorts-позначкою та попередній відбір за тривалістю. Жива видача
YouTube у твоєму регіоні потребує перевірки на твоєму ПК.
