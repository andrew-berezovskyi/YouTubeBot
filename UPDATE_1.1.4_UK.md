# Пошук вертикальних відео — 1.1.4

Встановлення поверх 1.1.3: закрийте бот, скопіюйте вміст архіву в C:\YouTubeBot із заміною файлів.

1. У PowerShell встановіть runtime, якщо його немає:
   winget install --id DenoLand.Deno -e
2. Після встановлення закрийте й відкрийте VS Code, щоб оновився PATH.
3. Запустіть UPDATE_SEARCH.bat. Він оновить yt-dlp разом з EJS, застосує профіль відбору та запустить діагностику.
4. Якщо всі перевірки OK, запускайте START_DISCOVERY.bat і «Знайти й перевірити».

Якщо winget відсутній: офіційні способи встановлення https://docs.deno.com/runtime/getting_started/installation/
Підтримуються Deno >=2.3 або Node >=22; бот передає знайдений runtime у yt-dlp явно.
Немає потреби перебудовувати EXE для запуску discovery через батник.

## Профіль відбору
- 5–180 секунд. Нижня межа 5 секунд — робочий вибір бота, не правило YouTube.
- Висота більша за ширину: 1080x1920 проходить, 1920x1080 і 1080x1080 — ні.
- Мінімальна висота залишається вашим налаштуванням (типово 720).
- До 60 результатів на запит; Shorts мають пріоритет. Короткі відео без Shorts URL також можуть пройти на перевірку метаданих.
- Позначка #shorts і мініатюра не є доказом вертикальності. Невідомі розміри не означають схвалення: після скачування обов'язковий FFprobe з урахуванням повороту та пропорцій пікселя.
- Уже відомі URL не витрачають ліміт нових кандидатів. Пошук обмежений першою вибіркою; це не повний обхід YouTube. Для нових результатів змінюйте запити або додавайте сторінки авторів /shorts.
- Перевірки водяних знаків, тематики, дублікатів і дозволів на використання залишаються. Вертикальний контейнер не гарантує, що всередині немає горизонтальної вставки або чорних полів.

UPDATE_SEARCH.bat зберігає попередній JSON у discovery_settings.before_1.1.4.json і змінює тільки профіль: min_duration=5, max_duration=180, vertical_only=true, youtube_shorts_only=false, youtube_scan_limit=60.
Зберігаються шляхи OCR, запити, дозволи та інші параметри. Старі відхилення за тривалістю повертаються на перевірку тільки якщо їх збережені метадані не суперечать новим фільтрам. Помилки із повідомленням JavaScript runtime також можна перевірити повторно. Інші відхилення, водяні знаки та історія публікацій не скидаються.

Помилка «This video is not available» не доводить, що причина лише в Deno. Відео може лишитися недоступним і після його встановлення. Тепер ERROR показується раніше за попередження.

YouTube підтримує квадратні/вертикальні Shorts до 3 хвилин; бот навмисно відбирає лише вертикальні:
https://support.google.com/youtube/answer/15424877?hl=en
Runtime та EJS:
https://github.com/yt-dlp/yt-dlp/wiki/EJS

Перевірено локальними тестами фільтрів, метаданих, повороту, дублікатів, аргументів runtime та попереднього конвеєра. Мережеві відповіді в тестах підмінені; реальне завантаження YouTube, Windows GUI та публікація в цьому середовищі не перевірені.
